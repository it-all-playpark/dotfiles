# VM sandbox-docker の外向き通信にだけ足す許可先。vm-egress-proxy の許可リストは、claude-code/settings.json の
# sandbox.network.allowedDomains とこのファイルの和を nix の評価時にまとめたもの（allowlist.nix）。
# - settings.json にあるドメインはここに書かない（同じドメインを 2 か所に書かない）
# - 最小限にし、1 行ずつ理由を書く。書式は allowedDomains と同じ（*.example.com はサブドメインだけに一致）
# - 足りないホストは ~/.local/state/vm-egress-proxy.err.log の denied の行で確かめる
get.docker.com # lima.yaml の provision が curl で取る docker の install スクリプト
download.docker.com # get.docker.com が足す docker の apt リポジトリと GPG 鍵
archive.ubuntu.com # VM（Ubuntu 26.04 arm64）の apt のミラー（/etc/apt/sources.list.d の URIs。ports.ubuntu.com は使わない）
security.ubuntu.com # VM の apt のセキュリティ更新のミラー
registry-1.docker.io # Docker Hub のレジストリ API（トークン発行の auth.docker.io は settings.json にある）
production.cloudflare.docker.com # Docker Hub の blob の配信元

dl-cdn.alpinelinux.org # alpine のイメージの apk のミラー
